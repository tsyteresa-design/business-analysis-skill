# 业务现状调研分析 Skill

一套 AI 辅助的中后台/复杂业务系统现状调研方法论，把单领域调研时间从 **2-3周压缩到3-5天**。

> 核心逻辑：AI 做信息的「初加工、结构化、检索、草稿输出」；你把时间留给访谈、验证、判断、对齐、建立信任。

## ✨ 这套Skill能帮你做什么

当你接手一个陌生的中后台系统，需要快速摸清楚真实业务现状时，这套skill可以帮你：

- 🚀 **效率提升70%+**：从零散文档/代码中自动提取结构化信息，省去80%的整理时间
- 📋 **标准框架输出**：统一的8模块调研报告结构，避免遗漏关键信息
- 🎯 **精准访谈**：自动按角色生成访谈提纲，只问AI搞不定的问题，不做无效沟通
- 🕵️ **自动发现问题**：缺口、冲突、代码缺陷、技术债自动标记，不藏在段落里
- 🔍 **100%可追溯**：每个事实都能回溯到代码行/文档章节/访谈记录，可自行验证
- 📊 **标准化可视化**：自动生成状态机、ER图、流程拓扑图，不用手动画图

## 🚀 快速开始

### 1. 安装Skill

**方式一：一键安装（推荐）**
```bash
# 克隆仓库到本地
git clone https://github.com/你的用户名/claude-business-analysis-skill.git
cd claude-business-analysis-skill

# 复制skill到Claude的skills目录
cp -R skills/* ~/.claude/skills/
```

**方式二：手动安装**
1. 下载本仓库
2. 将 `skills/` 目录下的两个文件夹复制到 `~/.claude/skills/` 目录
3. 重启Claude Code即可生效

### 2. 验证安装
在Claude Code中输入 `/business-domain-familiarization`，如果能看到skill说明即安装成功。

### 3. 第一个调研项目
1. 准备好目标领域的代码、数据库表结构、历史文档等材料
2. 输入 `/business-domain-familiarization` 启动调研流程
3. 按照skill给出的5步流程执行即可

## 📚 Skill详解

### 1. business-domain-familiarization（调研流程）
覆盖从材料收集到定稿的完整5步流程：
- **前置准备（0-1天）**：材料收集与完整性校验
- **步骤1：初稿生成（0.5天）**：AI基于代码/文档自动生成调研报告初稿
- **步骤2：信息校准（1-2天）**：按角色生成访谈提纲，访谈后自动合并信息、标记冲突
- **步骤3：可视化生成（0.5天）**：自动生成状态机、ER图、流程图等标准化可视化内容
- **步骤4：问题溯源（1天）**：自动关联git提交历史、工单记录，标记历史遗留问题与风险
- **步骤5：定稿同步（0.5天）**：自动关联术语表、打标签，同步知识库

### 2. business-status-report（报告规范）
定义了调研报告的标准框架与写作规范：
- **8个固定业务模块**：领域认知/系统架构/能力现状/权限矩阵/业务规则/数据模型/技术实现/已知问题，不可增减
- **5色状态标注体系**：🟢现网/🟡仅文档/🔴规划中/🚫缺口/⚠️冲突，全文强制打标，禁止裸文本
- **可视化规范**：状态机按阶段线性排列、ER图标注关键字段语义、表格化呈现所有规则
- **12个实战踩坑总结**：来自3版报告迭代的真实经验，避免你再踩同样的坑
- **质量自检清单**：14项检查项，确保报告质量

## ⚠️ 重要原则

1. **零脑补规则**：所有AI输出必须有可追溯来源，不确定的一律列入待确认清单，绝不虚构
2. **现状不做价值判断**：只客观陈述"代码写了什么/没写什么/哪里矛盾"，不评价设计好坏
3. **允许留白**：内容不全就标记为缺口，禁止为了"看起来完整"填充不确定信息
4. **"没有"比"有"更重要**：系统没做的校验/检查才是最危险的，必须专门记录
5. **不假设对称路径一致**：蓝字和红字、正向和逆向路径必须独立验证
